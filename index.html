Hướng Dẫn Sử Dụng

1. Quản Lý Thay Thế

Tab "Cài đặt" là nơi bạn quản lý các cặp từ khóa (Name, Địa danh, Skill...). Hỗ trợ Regex và Match Case.

2. Auto Caps & Format

Chọn kiểu định dạng hội thoại ở mục "Chuẩn Hóa Format". Hệ thống tự động nhận diện câu thoại để xử lý.

3. Chia Chương

Dán file text lớn vào, hệ thống sẽ chia nhỏ theo số lượng chương bạn muốn hoặc theo Regex.
